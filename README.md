# Gunsaw Rect Tool

A tool that combines the move/scale/rotate tools into one

REQUIRED: Gunsaw Level Editor+
https://github.com/jimmyking9999999/gunsaw-level-editor-plus

Hotkeys:
- **−/+** - Change the rect tool's grid snap for postion/scaling/rotation
- **Alt** - Disables grid snapping
- **Shift** - Resize while preserving the aspect ratio
- **Ctrl** - Rotate
